# 网络视频取证选择

网络画面优先发现 `video_url_start`、`video_read`、`video_next` 及当前说明。已连接时用 `video_doctor` 核实运行版本；工具不可用时按 [连接与能力前提](local-runtime.md) 处理。不把新版文件存在当成旧连接已经支持新参数。

## 按问题选择范围

宿主结合用户需求与字幕／转写的信息缺口，优先查看能补充信息及用户关注部分的组图，再按新增信息与耗时调整连续处理、速览、片段或定点补看范围。不固定全图阅读；满足用户明确要求，如实说明抽样与空隙。网页可能含多个视频或分P，核对返回条目身份。

## 增量画面与语言

用当前 MCP 的阅读计划记录所选全部／部分图片或文本方案，每批把图片与时码返回模型，实际查看后再确认并继续。不要在一个脚本中循环积累许多图片。接收失败重放待确认批次；服务器交付计数不证明模型已经收到或看过。

语言流程见 [文字说明](audio-text.md)。字幕为空时可继续看图；文字足够时也可以不读取组图。细节不清楚时局部补看。最终由宿主判断证据是否回答用户，不能因有大量可用图片却只看了片头，就把未完成的工作当成无法完成。

## 失败与回退

先区分 MCP 本机网络层错误与网站访问限制。地址校验失败时，核实服务版本及已有代理/DNS，具体诊断说明以 MCP 的 `video_help` 为准；不能把尚未发起的网络请求说成网站拒绝或视频不可读取。可处理的本地问题先解决，再考虑替代输入，不擅自更改系统网络设置。

解析器可能受网站变化、登录限制、媒体地址失效或网络条件影响。报告实际失败状态，不无限重试、不擅自读取浏览器 Cookie。视频串流经过有限恢复仍中断时，可使用 MCP 的同源完整视频下载回退，再由本地视觉流程补齐剩余范围；默认仍优先串流，不把完整下载当作必然更快。是否发生下载及覆盖结果以 MCP 返回状态为准，参数与限额见 video_help。若用户禁止完整下载，按当前 schema 关闭回退。

仍无法获取完整画面时说明缺失范围，不把文字齐全当成完整视频理解。可采用用户提供的本地媒体或其他可访问的同源媒体链接；外部字幕/转写只能补语言证据。本工具不提供屏幕采集回退。用户取消、选定任务已满足或确实无法继续时结束所属处理，保留已有结果并准确标记状态。

源服务器不支持定位时，跳转仍可能读取前面的数据；不要保证片段或速览必然更省流量。缩小输出图片不等于降低源流下载量。

连接或图片交付能力缺失时，见 [连接与能力前提](local-runtime.md)。读取路径后仍要实际查看图片，不能将工具可运行等同于已获得视觉证据。
