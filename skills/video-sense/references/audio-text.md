# 同源文字与外部文字的使用

画面、字幕、ASR 三类数据独立按需组合。纯视觉无需启用文字处理或安装 ASR；只取文字时，即使输入是视频，也可用 audio_start / audio_url_start 打开源，不创建图片任务。MCP 输入是音视频文件或链接，输出画面、可获取的同源字幕和按需 ASR；不接收外部字幕／转写文件。

## 选择来源

Skill 的默认取证顺序是先用可获取且来源可靠的字幕理解语言内容；字幕缺失、覆盖不足、不可靠，或任务需要核对时再使用 ASR 文本，也可保留双轨对照。这是宿主建议，不是 MCP 强制规则。 用户明确要求 ASR 或双轨时按请求取证，不自动双跑。

- 选择网络字幕时，用 `transcript_start` 的字幕模式列出同一条目提供的字幕，再选择实际返回的轨道。无字幕不等于无声音，也不妨碍看图。本地嵌入／旁挂字幕不自动提取；硬字幕随选中组图可见，不保证全文覆盖或输出完整文字。
- 字幕缺失、覆盖不足、不可靠，或用户要求识别／对照时，检查 `video_doctor` 的可选 ASR 条件后再识别当前任务音轨。不自动安装模型、改用其他模型或转发云端。
- 用户或外部工具已提供文字时，Agent 自行核实来源、剪辑版本和时间基准后直接使用，不导入 MCP。不能靠相似标题或文字看起来合理推定同源。来源不明时保留不确定性。

两者都取时分别调用字幕／ASR 模式建立轨道，并保存各自返回的文本轨 ID。每次读取明确传入相应 trackId，各自推进分页；不依赖默认最新轨，也不把两份原文自动合并或让 MCP 判断哪份更可信。

需要按外部文字补看时，只把已确认的原媒体时码传给图像工具。片段相对时间需要有可信映射；单一偏移不能修复不同剪辑或时间漂移。没有时码的全文不能强行关联逐帧。

## 增量读取与取证范围

`transcript_read` 按原媒体时间范围及游标分页读取，继续时沿用返回游标，避免反复塞入全文。处理 complete 不表示当前页含全部文字，生成中的空页也不表示以后没有新内容。若用户要求完整转写，检查实际覆盖及全部所需分页；只需局部证据时按任务决定阅读范围。

MCP 保留处理状态、覆盖范围和分页游标，供宿主决策；不追踪模型是否读完文字，也不把文字读完作为 `video_review finish` 的门槛。图片计划完成不能被解释为文字完整或答案充分。

视频任务的 `video_evidence` 可同时返回时间区间内的实际图片和该任务同源文字；纯音频直接读文字，无需图片。优先查看能补足字幕／转写缺口和用户关注部分的组图，再按新增信息与耗时决定扩展范围，不强制全部图片或 ASR。

## 解释状态和限制

源 ready、采集 complete 和转写 complete 分别表示媒体可处理、音轨获取完成和文字处理完成。ASR 已处理且标记 no_speech 才表示该范围未识别到语音；等待中或未启用的空列表不能称为静音。

图像时码来自采样网格，ASR 时码来自识别器估计。网络／处理耗时不是原媒体时间。同源关联也不能证明同步、文字准确或语义关系。overview 的未取样空隙不能被全片转写补成完整视觉覆盖。

区分直接看见的画面、字幕原文、ASR 识别与推测，不把转写称为自己直接听到。ASR 由 MCP 调用已配置后端；多个客户端可共享同一外置 ASR 配置、Python 环境和模型文件，不需逐 Agent 安装，但各进程仍可能分别加载模型。后端依赖、模型和配置以 MCP 及工具包 AUDIO-TEXT.md 为准；Skill 不包含模型或固定宿主环境。

## 网络读取回退

优先串流，有限同源恢复仍失败才按 MCP 配置下载完整音轨继续 ASR。用户禁止完整下载时关闭回退。按返回的实际传输状态说明是否发生下载；模型错误、取消不构成下载理由。不擅自换源或启用云端。
