# 连接与能力前提

MCP 技术名称为 `video-sense`，展示名为“动态视听”。多个 Agent 可以共用本 Skill 和同一份服务源码；各自管理连接、配置和任务数据。共享 Skill 只提供通用取证建议，不保存运行时位置、模型路径或客户端私有设置。

先发现当前会话可用工具。已连接时用 `video_doctor` 检查实际运行版本与依赖，必要时用 `video_help` 读取完整流程。参数以发现到的 schema 为准，不把磁盘上的新文件或其他会话的连接当成本会话已有能力。

工具尚不可用时，说明需要在当前客户端连接 video-sense；安装方式见完整工具包的 README 和 PORTABLE-README，由客户端自身的 MCP 配置机制决定。不要猜测私有路径、自动复制其他 Agent 的配置，或为连接问题改动无关服务和权限。本 Skill 不依赖某一种模型、专用工具或续跑机制。

视频视觉取证需要模型能处理图片，客户端也必须传递实际 image 内容。仅返回文件路径、manifest、文字元数据或工具成功状态不等于已查看画面。若环境已有其他获授权的图片查看方式，可使用实际保存的原件，但仍须如实记录查看范围，并遵守当前 MCP 阅读协议。不能查看图片时明确限制，不凭文字元数据编造画面。

同源网络字幕与可选 ASR 使用相应文字工具；外部转写由 Agent 自行核对并直接使用，不导入 MCP；先核实 `video_doctor` 报告的实际后端条件。不需要语言证据时无需配置 ASR。只取字幕／ASR 时使用独立 audio 入口，输入为视频也不需创建图片任务；需要画面才调用 video 入口。详细文本来源和对齐要求见 [文字证据说明](audio-text.md)。
